# Mini Clinic Information System

Sistem Informasi Klinik berbasis web yang dibangun dengan React.js, Node.js, Express.js, dan PostgreSQL.

## Deskripsi

Mini Clinic Information System adalah aplikasi web yang dirancang untuk membantu klinik dalam mengelola operasional sehari-hari, mulai dari pendaftaran pasien, antrean, pemeriksaan dokter, resep obat, hingga rekam medis berbasis metode SOAP.

## Fitur Utama

- ✅ Autentikasi pengguna dengan JWT
- ✅ Manajemen data pasien
- ✅ Manajemen data dokter
- ✅ Manajemen data poli
- ✅ Pendaftaran dan kunjungan pasien
- ✅ Sistem antrean otomatis
- ✅ Pemeriksaan dokter dengan metode SOAP
- ✅ Tindakan medis
- ✅ Resep obat
- ✅ Riwayat pemeriksaan pasien
- ✅ Dashboard statistik

## Teknologi

### Frontend
- React.js + Vite
- Tailwind CSS
- React Router DOM
- Axios
- React Hook Form + Zod
- Lucide React
- Recharts

### Backend
- Node.js + Express.js
- PostgreSQL
- Sequelize ORM
- JSON Web Token (JWT)
- bcryptjs
